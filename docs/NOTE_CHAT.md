# 노트 채팅

현재 노트를 AI에게 보여 주고 질문하거나 수정안을 받을 수 있는 선택 설치 확장입니다. 노트를 바꾸면 그 노트의 대화로 바뀝니다.

## 시작하기

1. **설정 → 확장**에서 **노트 채팅**을 설치하고 활성화합니다.
2. 확장의 **설정**을 열고 연결할 서버의 **API Base URL**, **모델 ID**, **API 키**를 입력해 저장합니다.
3. 노트를 열고 오른쪽 **노트 채팅**에 요청을 적습니다. `<leader>ac` 또는 명령 팔레트의 **현재 노트와 채팅**으로 오른쪽 사이드바를 열 수 있습니다. 키 조합은 일반 확장 명령처럼 설정에서 바꿀 수 있습니다.

서버가 OpenAI의 **Chat Completions** 요청·응답 형식을 지원해야 합니다. Base URL에는 보통 `https://서버주소/v1`을 입력합니다. Foltra는 `/chat/completions`를 붙이며, 이미 해당 경로까지 입력했다면 중복해서 붙이지 않습니다. 모델 ID와 API 키는 사용하는 서버가 발급한 값을 사용하세요. 인증 없는 로컬 서버에서는 키를 비워둘 수 있습니다.

외부 서버는 HTTPS를 사용합니다. 같은 컴퓨터의 `localhost`, `127.0.0.1`, `::1` 서버에는 HTTP도 허용합니다. OpenAI를 직접 연결할 때는 `https://api.openai.com/v1`을 사용합니다. 서버별 모델 지원과 이용 요금은 해당 서비스에 따릅니다.

## 질문과 수정 제안

| 모드 | 예시 | 답변을 받은 뒤 |
| --- | --- | --- |
| 질문 | “핵심 내용을 세 줄로 요약해 줘” | 필요하면 **노트 끝에 추가** |
| 수정 제안 | “중복 표현을 줄이고 문단을 정리해 줘” | 전체 수정안을 읽고 **수정안 적용** |

- **Enter**는 전송, **Shift+Enter**는 줄바꿈입니다. 한글 조합 확정 Enter는 전송으로 처리하지 않습니다.
- 보내기 전에 현재 노트를 저장합니다. 저장에 실패하면 전송하지 않습니다.
- 답변만 받아서는 노트가 바뀌지 않습니다. **수정안 적용**은 본문 전체를 교체하므로 제안을 확인한 뒤 누르세요.
- 답변을 만드는 동안 노트를 수정했다면 오래된 수정안 적용을 거절합니다. 현재 상태를 확인하고 새 수정안을 요청하세요.
- 대화 비우기는 확인 후 현재 노트의 기록만 지웁니다. 노트 본문은 지우지 않습니다.
- 요청 중에도 다른 노트를 편집할 수 있습니다. 같은 노트에는 동시에 한 번만 요청합니다.

## 저장·전송 범위

요청할 때 **현재 노트 제목과 저장된 Markdown 본문, 최근 대화 최대 20개 메시지, 이번 요청**을 설정한 서버로 전송합니다. 다른 노트를 검색해서 가져오거나, 첨부파일·이미지 자체를 업로드하거나, 도구를 실행하지 않습니다. 서버가 반환한 이미지도 자동으로 내려받지 않습니다.

대화는 노트별 최근 100개 메시지(질문·답변 각각 1개)를 vault의 `.foltra/local/ai-chat/<확장 ID>/<노트 ID>.json`에 저장합니다. 이 경로는 Git 동기화·vault 내보내기에서 제외됩니다. 앱을 다시 열어도 같은 기기의 기록은 남습니다.

Provider 설정과 API 키는 vault 밖의 기기 앱 데이터에 vault·확장별로 보관합니다. vault 내보내기나 Git에 포함하지 않으며, 키를 조회 명령이나 확장 JavaScript에 반환하지 않습니다. macOS/Linux에서는 파일 권한을 소유자 읽기·쓰기(`0600`)로 제한합니다. **OS 키체인 암호화 저장은 아닙니다.** 컴퓨터 전체 백업에는 포함될 수 있습니다. API 주소를 바꾸면 이전 키를 지우므로 새 주소용 키를 다시 입력하세요. 설정에서 키를 삭제할 수도 있습니다.

현재는 답변이 완료된 뒤 한 번에 표시하며 요청 제한 시간은 90초입니다. 요청 문장은 UTF-8 16KB, 노트 본문과 답변은 각각 160KB, 전송 내용 전체는 400KB까지 지원합니다. 스트리밍, 도구 실행, 여러 노트 검색, 이미지 입력은 지원하지 않습니다. 모델의 답변은 부정확할 수 있으므로 적용 전에 내용을 확인하세요.

## 확장과 CLI 계약

`examples/code/note-chat/`의 실제 설치 패키지는 `ai.chat`, `notes.read`, `notes.write`, `ui` 권한을 선언합니다. 호스트가 렌더링하는 `{type:'note-chat'}`과 `{type:'ai-settings'}`만 사용하며, QuickJS에 HTTP나 API 키 접근 권한을 추가하지 않습니다.

공통 코어의 `chat.settings`, `chat.configure`, `chat.history`, `chat.send`, `chat.clear`, `chat.apply`를 CLI에서도 사용할 수 있습니다. `foltra chat.send --help`에서 인자를 확인하세요. 모두 활성화된 확장의 `pluginId`와 `pluginDigest`를 검사하며, 변경 명령은 `expectedRevision`을 요구합니다. Provider 설정 revision, 대화 revision, 적용할 노트 revision은 서로 다릅니다. API 키를 CLI로 설정한다면 셸 기록에 남지 않도록 JSON 표준입력을 사용하세요.

참고: [OpenAI Chat Completions 공식 API](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create).
