# 작업 항목

목록 시작의 작업 표시를 Live Preview와 읽기 모드에서 같은 아이콘으로 표시합니다.

닫는 `]` 뒤에 공백(또는 탭)을 입력해야 아이콘으로 바뀝니다. `- [ ]`까지만 입력하면 원문을 유지하고, `- [ ] ` 상태에서 내용을 이어 쓰면 아이콘을 유지합니다. `- [ ]aaa`처럼 구분 없이 붙여 쓴 것은 작업 항목으로 렌더링하지 않습니다. 이 규칙은 모든 상태에 동일하게 적용합니다.

| Markdown            | 상태              |
| ------------------- | ----------------- |
| `- [ ] 할 일`       | 할 일             |
| `- [/] 작업 중`     | 진행 중           |
| `- [x] 완료`        | 완료 (`X`도 지원) |
| `- [b] 기억할 내용` | 북마크            |
| `- [-] 취소`        | 취소              |
| `- [>] 나중에`      | 미룸              |
| `- [?] 확인 필요`   | 질문              |
| `- [!] 중요`        | 중요              |
| `- [*] 주목할 내용` | 별표              |
| `- [i] 참고 정보`   | 정보              |
| `- [p] 고정할 내용` | 핀                |

영문 마커는 대소문자를 모두 지원합니다. 앱의 **설정 → 편집기 → 작업 항목과 아이콘**에서 실제 아이콘과 전체 목록을 볼 수 있습니다. `[b]`는 북마크이며 차단 상태가 아닙니다.

Live Preview에서는 아이콘을 클릭하거나 방향키·Vim `h`/`l`로 불릿·마커 안에 커서를 옮기면 `- [ ]` 전체 원문이 드러납니다. 위의 모든 상태에 동일하게 적용하며 `-`, `+`, `*` 또는 목록 번호부터 대괄호 안의 상태 문자까지 직접 수정할 수 있습니다. 커서를 밖으로 옮기면 다시 아이콘으로 표시합니다. Vim에서는 Insert 모드로 문자를 수정합니다. 같은 줄의 본문을 편집할 때는 아이콘이 유지됩니다. 읽기 모드에서는 원문이 드러나지 않습니다.

편집기의 불릿 줄에서 **Cmd+L**(Windows/Linux에서는 **Ctrl+L**)로 작업 상태를 바꿉니다.

일반 불릿 → `[ ]` → `[/]` → `[x]` → `[ ]`

다른 작업 상태에서 누르면 `[ ]`로 돌아옵니다. 본문과 들여쓰기를 유지하며 실행 취소할 수 있습니다. 설정의 단축키에서 **작업 상태 순환** 명령을 찾아 변경·해제하거나 leader 조합을 지정할 수 있습니다. 읽기 모드와 속성 입력칸에서는 본문을 변경하지 않습니다.

`-`, `*`, `+`와 번호 목록의 아이콘 표시를 지원하며 단축키 순환은 불릿 목록에 적용합니다. 코드 블록·인라인 코드·YAML 속성·일반 문장의 대괄호는 작업 항목으로 바꾸지 않습니다. 아이콘 클릭은 원문 편집 위치로 이동하며 상태를 순환시키지 않습니다.
