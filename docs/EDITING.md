# 서식 편집과 Vim text object

설정 → Vim 및 단축키에서 Vim을 켜거나 키 조합을 변경할 수 있습니다. 서식 명령은 Vim을 끈 상태에서도 사용할 수 있습니다. 아래 Leader 기본값은 Space입니다.

| 서식 | macOS 기본 키 | Leader | 저장 문법 |
| --- | --- | --- | --- |
| 굵게 | Cmd+B | `<leader>mb` | `**텍스트**` |
| 기울임 | Cmd+I | `<leader>mi` | `*텍스트*` |
| 밑줄 | Cmd+U | `<leader>mu` | `<u>텍스트</u>` |
| 취소선 | Cmd+Shift+X | `<leader>ms` | `~~텍스트~~` |
| 인라인 코드 | Cmd+Shift+C | `<leader>mc` | `` `텍스트` `` |

다른 운영체제에서는 Cmd 대신 Ctrl을 사용합니다. 기울임만 Ctrl+Shift+I이며, Ctrl+I는 기존 앞으로 이동을 유지합니다. 각 명령은 `note.format.bold/italic/underline/strike/code`로 검색하고 일반 키·Leader 키·Vim 연속 키를 변경하거나 해제할 수 있습니다.

선택 영역이 있으면 선택한 텍스트에, 없으면 커서가 있는 단어에 적용합니다. 빈 위치에서는 기호 사이에 커서를 놓습니다. 같은 명령을 다시 실행하거나 이미 서식이 있는 영역 안에서 실행하면 해제합니다. 여러 줄 선택은 줄마다 적용하며 목록·작업·제목·인용 접두부와 빈 줄을 보존합니다. 실행 취소와 자동 저장은 일반 편집과 같습니다.

서식 명령은 본문에 포커스가 있을 때만 동작합니다. 명령 팔레트에서는 편집 중인 노트로 포커스를 돌려 실행합니다. 읽기 모드·설정 입력칸·한글 조합 중에는 본문을 변경하지 않습니다. 코드 블록·YAML 속성·링크·임의 HTML 내부와 일부 원문 경계(닫는 기호를 이스케이프하는 끝 역슬래시)는 보호합니다.

밑줄은 Markdown 기본 문법이 아니므로 정확한 `<u>`와 `</u>` 쌍만 별도로 표시합니다. 속성·스크립트 등 임의 HTML 실행은 허용하지 않습니다. 같은 문단의 밑줄, 중첩 서식, 표 셀은 지원하고 링크 라벨 안의 태그나 여러 블록을 가로지르는 HTML은 지원하지 않습니다. Live Preview에서 편집하는 줄은 태그를 드러내 수정할 수 있습니다.

굵게는 읽기·라이브 프리뷰·소스 편집에서 700 굵기와 테마에 맞춘 강조색을 함께 사용합니다. 테마가 `strong` 색상을 지정하지 않으면 본문색에 강조색을 살짝 섞고 배경 대비를 보정합니다. 실제 획의 굵기는 선택한 글꼴에 따라 달라집니다.

## 목록 편집

빈 체크박스 줄에서 Backspace는 `- [ ] `의 문자를 커서 앞에서 하나씩 지웁니다. 하위 목록의 들여쓰기나 이전 줄을 한꺼번에 제거하지 않습니다. `[/]`, `[b]` 등 다른 상태도 같으며, Enter는 기존처럼 빈 목록을 해제합니다.

Vim에서 `dt` → Space는 다음 공백 직전까지, `df` → Space는 다음 공백을 포함해 삭제합니다. 문자 인수나 연산자를 입력 중일 때는 Space를 leader 키로 가로채지 않습니다. 명령을 마치거나 Esc로 취소하면 다시 leader 키를 사용할 수 있습니다.

## Vim text object

`i`는 안쪽, `a`는 둘러싼 기호/공백까지 포함합니다. `d`(삭제), `c`(바꾸기), `y`(복사), `v`(선택) 뒤에 조합합니다.

| 대상 | 안쪽 / 전체 | 예시 |
| --- | --- | --- |
| 단어 / 공백으로 구분한 WORD | `iw/aw`, `iW/aW` | `ciw` 단어를 지우고 Insert 진입 |
| 문장 / 문단 | `is/as`, `ip/ap` | `vip` 문단 선택 |
| 괄호 | `i(/a(`, `i)/a)` 및 `[]`, `{}`, `<>` | `di)` 괄호 안 삭제 |
| 여러 종류의 괄호 | `ib/ab`, `iB/aB` | `ib`는 가장 가까운 `()`, `[]`, `{}` 안쪽, `iB`는 `{}` |
| 따옴표 / 백틱 | `i"/a"`, `i'/a'`, `` i`/a` ``, `iq/aq` | `yiq` 가장 가까운 따옴표 안 복사 |
| 함수 호출 | `if/af` | `vaf` 함수 이름부터 닫는 괄호까지 선택 |
| 인수 | `ia/aa` | `daa` 인수와 쉼표 삭제 (중첩·인용된 쉼표 구분) |
| `*` 강조·굵게 | `i*/a*` | `ci*` 강조 내용만 변경 |
| `_` 강조·굵게 | `i_/a_` | `va_` 강조 기호까지 선택 |
| 취소선 | `i~/a~` | `di~` 내용만 삭제 |
| 태그 쌍 | `it/at` | `cit` `<u>…</u>` 등 태그 안 변경 (중첩·속성 포함 원문) |
| 구분 문자 | `i구분자/a구분자` | `vi_` 식별자의 `_` 사이 선택, `a`는 오른쪽 구분자 포함 |
| 직접 지정한 문자열 쌍 | `i?/a?` | `ci?` → 시작·끝 구분자를 입력하고 내용 변경 |

여는 괄호를 쓰는 `i(`, `i[`, `i{`, `i<`는 안쪽 양끝 공백을 제외하고, 닫는 괄호를 쓰는 `i)`, `i]`, `i}`, `i>`는 공백을 유지합니다. Markdown 강조·굵게·취소선에서는 기존처럼 `a*/a_/a~`가 양쪽 서식 기호를 포함합니다. 강조 구문 밖에서는 같은 문자를 일반 구분자로 사용할 수 있습니다. 태그 text object는 원문 편집 기능이며 임의 HTML 렌더링을 허용하지 않습니다.

현재 줄에서 커서를 감싼 대상을 먼저 찾고, 없으면 다음 대상을 찾습니다. 현재 줄에 대상이 없을 때만 주변 50줄까지 탐색합니다. `2ib`처럼 개수를 붙이거나 Visual에서 `ib`를 반복하면 중첩된 바깥 대상으로 확장하고 이어서 다음 대상으로 이동합니다.

| 이동 방식 | 예시 |
| --- | --- |
| 다음 대상 | `vinq` 다음 따옴표 안 선택, `cinf` 다음 함수 내부 변경 |
| 이전 대상 | `vilq` 이전 따옴표 안 선택, `cilf` 이전 함수 내부 변경 |
| 시작 / 끝 경계 | `g[b` / `g]b` 괄호의 시작 / 끝으로 이동 |

`i?`/`a?`는 편집기 하단에서 두 문자열을 차례로 입력합니다. Enter로 확정하고 Esc로 취소하며 정규식 대신 입력한 문자열 그대로 찾습니다. `.` 반복은 확정한 문자열 쌍을 재사용합니다. 한글 조합 중 Enter는 구분자를 확정하지 않습니다.

[mini.ai](https://github.com/nvim-mini/mini.ai)의 기본 사용법을 참고한 구현입니다. 기본 단어·문장·문단과 Normal의 `i`/`a`는 기존 Vim 동작을 유지합니다. 객체의 삭제·변경·복사, Visual 선택·반복 확장, 횟수·레지스터·undo·`.` 반복과 한글 물리 키 처리를 검사했습니다. 언어별 AST 대신 제한된 텍스트 구조 탐색을 사용하며 Lua 사용자 함수·Tree-sitter 연동은 포함하지 않습니다. 큰 문서에서 키 입력을 막지 않도록 탐색은 최대 10만 문자, 횟수는 1,000회까지 지원합니다.

예를 들어 `viw` → `<leader>mb`로 단어를 굵게 만들고, 선택을 유지한 채 `<leader>mu`로 밑줄을 더할 수 있습니다. 서식 명령에 지정한 Leader 없는 조합도 Normal과 Visual에서 동작합니다. Insert에서는 일반 텍스트 입력을 유지합니다.

설정 화면에서는 Esc로 이전 화면과 포커스로 돌아갑니다. 열린 팝업·드롭다운·키 기록이 있으면 그 작업이 먼저 Esc를 처리합니다.
