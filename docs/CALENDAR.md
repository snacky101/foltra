# 일지 캘린더

설정 → 확장에서 **일지 캘린더**를 설치하고 노트 읽기·쓰기·화면 표시 권한을 승인하면 우측 사이드바 하단에 달력이 나타납니다. 패키지 ID는 `daily-calendar`이며 오늘 노트 생성도 이 확장에 포함됩니다. 기존 1.0.0 사용자는 확장을 1.1.0으로 업데이트한 뒤 다시 활성화합니다.

- 오늘 날짜를 강조하고 `YYYY-MM-DD`와 정확히 일치하는 제목의 노트가 있는 날 아래에 점을 표시합니다. 예를 들어 `2026-09-17`은 표시하고 `2026-09-17 회의`나 날짜가 아닌 제목·잘못된 날짜는 표시하지 않습니다.
- 이전·다음 달과 오늘 버튼으로 이동합니다. 앱을 새로 실행하거나 확장을 다시 활성화하면 컴퓨터의 현재 지역 날짜를 기준으로 이번 달로 돌아옵니다. 월 이동은 현재 세션에만 보관하며 시작할 때 노트를 생성하지 않습니다.
- 날짜에 노트가 하나면 바로 엽니다. 같은 날짜 제목이 여러 개면 목록에서 고릅니다. 긴 목록은 20개씩 넘길 수 있습니다.
- 확장의 **설정**에서 **노트가 없는 날짜를 누르면 생성** 옵션을 선택합니다. 기본값은 꺼짐이며, 이때 빈 날짜를 누르면 토스트로 안내합니다. 켜면 해당 날짜를 제목으로 빈 노트를 만들고 엽니다. 기존 노트의 본문·폴더·revision은 그대로 유지합니다.
- 명령 팔레트의 **오늘의 노트 열기**는 위 옵션과 관계없이 오늘 노트가 없으면 만들고 있으면 엽니다. 기본 단축키는 macOS의 **Cmd+Shift+d**(다른 운영체제는 Ctrl+Shift+d)와 **`<leader>nd`**이며 설정에서 변경·해제할 수 있습니다. 오늘 노트가 여러 개면 캘린더의 선택 목록을 엽니다.
- 노트를 생성·이름 변경·삭제하면 vault 갱신을 통해 점과 목록을 다시 계산합니다. 생성일이나 수정일이 날짜인 일반 노트를 일지로 해석하지 않습니다. 안내와 실행 오류는 토스트로 표시해 달력 아래에 경고 영역을 추가하지 않습니다.

명령 ID는 `plugin.daily-calendar.open-today`(오늘 노트), `plugin.daily-calendar.today`(현재 월로 복귀), `plugin.daily-calendar.previous-month`, `plugin.daily-calendar.next-month`입니다. 기존 **캘린더 오늘로 이동**은 화면의 월만 바꾸며 노트를 만들지 않습니다. 월 이동 명령에는 기본 전역 단축키가 없습니다.

확장은 공통 SDK의 `runtime.views[].placement: 'right-sidebar'`와 제한된 `calendar` 뷰 노드, 설정 폼을 사용합니다. 생성은 기존 `note.open-link` 명령을 사용하며 임의 DOM·HTML·CSS·파일 접근을 허용하지 않습니다. 노트 목록 조회는 기존 SDK 응답·실행 시간 제한을 따릅니다.
