# 일지 캘린더

설정 → 확장에서 **일지 캘린더**를 설치하고 노트 읽기·화면 표시 권한을 승인하면 우측 사이드바 하단에 달력이 나타납니다. 패키지 ID는 `daily-calendar`입니다. 노트 원문이나 플러그인 저장 데이터를 변경하지 않습니다.

- 오늘 날짜를 강조하고 `YYYY-MM-DD`와 정확히 일치하는 제목의 노트가 있는 날 아래에 점을 표시합니다. 예를 들어 `2026-09-17`은 표시하고 `2026-09-17 회의`나 날짜가 아닌 제목·잘못된 날짜는 표시하지 않습니다.
- 이전·다음 달과 오늘 버튼으로 이동합니다. 앱을 새로 실행하거나 확장을 다시 활성화하면 컴퓨터의 현재 지역 날짜를 기준으로 이번 달로 돌아옵니다. 월 이동은 현재 세션에만 보관합니다.
- 날짜에 노트가 하나면 바로 엽니다. 같은 날짜 제목이 여러 개면 목록에서 고릅니다. 긴 목록은 20개씩 넘길 수 있습니다. 노트가 없는 날은 안내만 표시하고 새 노트를 만들지 않습니다.
- 노트를 생성·이름 변경·삭제하면 vault 갱신을 통해 점과 목록을 다시 계산합니다. 생성일이나 수정일이 날짜인 일반 노트를 일지로 해석하지 않습니다.

명령 팔레트와 단축키 설정에서 **캘린더 오늘로 이동**, **캘린더 이전 달**, **캘린더 다음 달**을 사용할 수 있습니다. 명령 ID는 `plugin.daily-calendar.today`, `plugin.daily-calendar.previous-month`, `plugin.daily-calendar.next-month`이며 기본 전역 단축키는 지정하지 않습니다.

확장은 공통 SDK의 `runtime.views[].placement: 'right-sidebar'`와 제한된 `calendar` 뷰 노드를 사용합니다. 다른 확장도 같은 계약으로 사이드바 뷰를 추가할 수 있으며 임의 DOM·HTML·CSS·파일 접근을 허용하지 않습니다. 노트 목록 조회는 기존 SDK 응답·실행 시간 제한을 따릅니다.
