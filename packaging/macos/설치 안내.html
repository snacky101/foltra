나만의 기록을 시작해요.

DMG 창에서 Foltra.app을 Applications 폴더로 끌어다 놓으세요.

Foltra.app→Applications

이미 설치했다면 다음 단계로 넘어가세요. 이 안내는 인터넷 없이도 볼 수 있습니다.

응용 프로그램에서 실행하세요.

Finder의 응용 프로그램에서 Foltra를 더블클릭하세요.

“Apple은 Foltra에 악성 코드가 없음을 확인할 수 없습니다”가 뜨나요?

현재 프리뷰는 Apple Developer ID 서명·공증 전입니다. 경고창을 닫고 다음 단계에서 직접 열기를 허용할 수 있습니다. 정상적으로 실행됐다면 이 안내를 닫아도 됩니다.

설정에 Foltra의 열기 버튼이 나타나려면, 먼저 앱을 한 번 실행해야 합니다.

설정에서 Foltra 열기를 허용하세요.

아래 버튼으로 설정을 연 뒤, 개인정보 보호 및 보안의 아래쪽 보안 영역을 확인하세요.

개인정보 보호 및 보안 열기 ↗

설정이 열리지 않으면 DMG 창의 보안 설정.inetloc 파일을 더블클릭하세요.

  1. Foltra 옆의 확인 없이 열기(Open Anyway)를 누르세요.
  2. 인증을 요청하면 Mac 암호 또는 Touch ID로 확인하세요.
  3. 다시 표시되는 확인창에서 열기를 누르세요.
설정이나 열기 버튼이 보이지 않나요?

브라우저에서 시스템 설정 열기를 물으면 허용하세요. 새 창에 오류가 나오거나 설정이 열리지 않으면 DMG 창의 보안 설정.inetloc 파일을 더블클릭하세요. 직접 이동하려면 Apple 메뉴 → 시스템 설정 → 개인정보 보호 및 보안으로 직접 이동하세요. 이전 macOS에서는 시스템 환경설정 → 보안 및 개인 정보 보호 → 일반입니다. Foltra를 다시 실행한 뒤 설정을 확인하세요. 조직에서 관리하는 Mac은 관리자의 제한이 있을 수 있습니다.

이제 Foltra에서 만나요.

Foltra의 시작 화면에서 새 vault를 만드세요. Vault는 노트와 데이터를 담는 내 컴퓨터의 폴더입니다.

다음부터는 응용 프로그램에서 Foltra를 평소처럼 열면 됩니다.

이 안내 창과 DMG 창은 닫아도 됩니다.

열기 승인은 사용자가 직접 진행합니다. 이 안내는 Mac의 보안 설정을 변경하지 않습니다.
